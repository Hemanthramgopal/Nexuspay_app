# Specification: React & FastAPI Networking Fix (Unit 13.7)

## Overview
The React frontend (port 5173) is failing to communicate with the FastAPI backend (port 8011) due to incorrect API base URLs and potential CORS restrictions.

## Core Requirements

1. **Frontend API URL Update**:
   - Locate the `fetch()` or `axios` call in the React application (likely in `App.jsx`, `ChatInterface.jsx`, or an `api.js` utility).
   - Change the relative endpoint (e.g., `/api/v1/semantic-negotiation`) to the absolute backend URL: `http://127.0.0.1:8011/api/v1/semantic-negotiation`.

2. **Backend CORS Configuration**:
   - Open `app/main.py`.
   - Ensure `fastapi.middleware.cors.CORSMiddleware` is imported and added to the app.
   - Configure `allow_origins` to explicitly include `["http://localhost:5173", "http://127.0.0.1:5173"]` (or `["*"]` for local development).
   - Ensure `allow_methods=["*"]` and `allow_headers=["*"]`.
