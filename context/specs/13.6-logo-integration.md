# Specification: V1 Logo Integration & Header Styling (Unit 13.6)

## Overview
Reintroduce the original NexusPay logo from the Vanilla JS version into the new React + Tailwind application. The logo must be recolored to match the premium fintech design system established in Unit 13.5.

## Core Requirements

1. **Header Layout**:
   - Create or update the top navigation/header component.
   - Use a crisp white background with a subtle bottom border (`bg-white border-b border-slate-200`).
   - Keep the header padding generous to match the overall layout spacing (e.g., `px-8 py-4`).

2. **Logo Styling (Tailwind Integration)**:
   - Apply a sharp, structured typographic style: `text-2xl font-extrabold tracking-tight`.
   - Use a dual-color text approach to match the new theme: 
     - "Nexus" in `text-slate-800`
     - "Pay" in `text-blue-600`
   - If an SVG icon was part of the original logo, apply `fill-current text-blue-600` to it.

3. **Alignment**:
   - Ensure the logo is perfectly vertically aligned with any header action buttons (like the "Live Negotiation" badge) using `flex items-center justify-between`.
