# Specification: Fintech Premium UI Overhaul (Unit 13.5)

## Overview
Elevate the React + Tailwind UI to a premium, Razorpay-inspired SaaS aesthetic. Maintain the side-by-side layout but overhaul the typography, colors, shadows, and component containment to feel like an enterprise payment dashboard.

## Core Design System (Tailwind)

1. **Global Canvas & Typography**:
   - Background: Ultra-light gray/blue (`bg-slate-50`).
   - Font: Apply standard crisp sans-serif (e.g., `font-sans antialiased`).
   - Text Colors: `text-slate-800` for primary headings, `text-slate-500` for secondary text.

2. **Chat Interface (The Consumer View)**:
   - Container: Crisp white card (`bg-white`), soft shadow (`shadow-lg shadow-slate-200/50`), rounded corners (`rounded-2xl`), subtle border (`border border-slate-100`).
   - Agent Bubbles: Light slate (`bg-slate-100`), dark text (`text-slate-800`), rounded-br-none.
   - User Bubbles: Razorpay-style bright blue (`bg-blue-600`), white text (`text-white`), rounded-bl-none.
   - Input Field: High padding, minimal border (`border-slate-200 focus:ring-2 focus:ring-blue-500 focus:border-blue-500`).

3. **Audit Terminal (The Developer View)**:
   - Container: Deep Midnight Navy (`bg-[#0a1128]`), sharp contrast to the light chat side. Soft glow shadow (`shadow-xl`).
   - Font: Monospace for logs (`font-mono text-sm`).
   - Success Logs (Green): Muted emerald text (`text-emerald-400`), subtle borders (`border-emerald-900/50`), dark green faint backgrounds (`bg-emerald-900/20`).
   - Blocked Logs (Red): Vivid rose/red (`text-rose-400`), subtle borders (`border-rose-900/50`), dark red faint backgrounds (`bg-rose-900/20`).
   - Trace Header: Small, tracked-out uppercase (`tracking-wider text-slate-400 text-xs`).

4. **Layout Spacing**:
   - Increase the gap between the Chat and the Audit Terminal to give both components "breathing room" (`gap-8` or `gap-12`).
   - Ensure the main wrapper has generous padding (e.g., `p-8` or `max-w-7xl mx-auto`).
